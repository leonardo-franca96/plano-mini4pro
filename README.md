# Plano de voo — DJI Mini 4 Pro

Página para desenhar a área de mapeamento, ajustar sobreposição, altura, velocidade e grade,
e baixar o plano em KMZ para importar no DJI Fly.

Abra: https://leonardo-franca96.github.io/plano-mini4pro/

Gerada a partir do projeto Mapeamento DJI (`./gradlew :web:site`).
